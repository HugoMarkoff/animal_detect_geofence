# JSON examples

These files are small schema examples for the main outputs used in the minimal live phase.

They are examples only:

- they are not read by the app
- they are not generated artifacts
- they exist to document the intended structure for GitHub contributors and downstream consumers

Available examples:

- `geofence-simple.example.json`: item-level country allow-list snapshot
- `country-pack.example.json`: detailed per-country pack entry with a regional polygon
- `review-queue.example.json`: optional JSON mirror of the review queue
- `binary-overrides.example.json`: global binary review decisions
- `country-override.example.json`: per-country manual patch or removal file
