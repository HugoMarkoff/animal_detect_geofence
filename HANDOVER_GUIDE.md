# Handover Guide

## Purpose

This repository is the handoff target for the country-pack review workflow.

The goal is to let reviewers:

1. inspect the current country pack,
2. see which species are treated as national or regional,
3. draw new regional polygons when needed,
4. draft structured GitHub issues for additions, corrections, and removals.

## What was moved here

The following runtime pieces were copied from the original workspace:

- `suggestion_app/`
- `data/animals-global.json`
- `data/precomputed-countries/`

Those are the files the review app needs in order to run independently.

The repository now also includes a static GitHub Pages entrypoint at `index.html` with root-level `assets/`.

## Runtime notes

- The GitHub Pages version is fully static and has no backend.
- The frontend has no build step.
- Pages can publish directly from the repository root on `main`; no dedicated `gh-pages` content branch is required.
- Leaflet, Leaflet.Draw, Turf, and polygon-clipping are loaded from CDNs.
- For local static preview, use `python -m http.server 8081` from the repo root.
- GitHub draft links default to `HugoMarkoff/animal_detect_geofence` unless `GITHUB_ISSUE_REPO` is overridden.

## Current workflow

1. Select a country.
2. Review the current pack and existing regional overlays.
3. Choose `addition`, `correction`, or `removal`.
4. For regional changes, draw polygon suggestions directly on the map.
5. Add the mandatory explanation.
6. Build a ticket preview.
7. Copy the markdown or open a prefilled GitHub issue draft.

## Data assumptions

- `animals-global.json` is the source of species labels and ids.
- `precomputed-countries/*.json` is the source of country membership, status bucket, and stored regional polygons.
- Many countries are still baseline packs, so they may only have country-level membership and no footprint geometry.
- Denmark is currently the most validated pack and includes regional footprints.

## What is not moved yet

This repo does not yet include:

- the SpeciesNet testing app,
- the full build pipeline scripts that regenerate the country packs,
- the original radar app.

That is intentional for now. This repository is focused on the review-and-ticket workflow.
